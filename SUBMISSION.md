# Brief project description (for the submission form)

CareCircle is a shared elderly-care platform where the elderly person stays at the centre of their own healthcare. One care circle per elder; family members and caretakers join with an invite code and a simple numeric family passcode - no accounts or apps to install. Everyone manages the same profile: medication schedules with one-tap Taken/Missed/Skip tracking and a weekly adherence score, upcoming doctor appointments, and a transparent activity log of who did what. A background service proactively emails the circle through the Gmail API when a dose is due, a dose is missed, or an appointment is within 24 hours. Built elder-first: large type, high contrast, big buttons, screen-reader friendly, mobile responsive. Node.js + Express, containerized for Cloud Run, with an automated test suite and security-hardened sessions (scrypt-hashed passcodes, rate limiting, strict CSP).
